# 프론트엔드

`main.html`을 브라우저에서 열어 확인합니다. 시작하기 후 학적 단계와 이용 이유를 선택합니다. 전공지식을 선택하면 수업을 검색해 여러 개 추가하고, 그 외의 이유는 수업 단계 없이 선배 특징 점수로 이동합니다. 이후 각 특징의 중요도를 1~5점으로 선택합니다. 로그인은 준비 중입니다.

수업 검색 목록은 화면 확인을 위한 예시이며 실제 학교 수업 목록과 연결되지 않았습니다. 목록에 없는 수업은 이름을 입력해 직접 추가할 수 있습니다.

선택 완료 시 `sessionStorage`의 `ppunppun-choice`에 JSON을 저장하고 `frontend/choice/`로 이동합니다. 하단 메뉴는 `frontend/choice/`, `frontend/chat/`으로 연결됩니다. 두 화면은 아직 구현되지 않았습니다.

```json
{
  "schema_version": 1,
  "basic_info": {"status": "재학생"},
  "interests": {"reason": "전공지식", "courses": ["자료구조", "알고리즘"]},
  "preferences": {"ratings": {"friendly": 5, "empathetic": 5, "course_experience": 4, "academic_knowledge": 5, "study_advice": 4}}
}
```

전공지식 외의 이용 이유에서는 `courses`가 빈 배열입니다. 점수는 해당 특징의 중요도를 나타냅니다. 데이터는 현재 브라우저 탭에 임시 저장되며 외부 LLM이나 서버에 전송되지 않습니다. 실제 선배 추천은 구현되지 않았으며, 백엔드 연동 시 이 구조를 활용할 수 있습니다. API 형식과 개인정보 처리 및 전송 동의 절차는 팀에서 확정해야 합니다. API 키는 프론트엔드에 넣지 않습니다.

선배 특징은 이용 이유에 따라 달라집니다. 친근함과 공감 능력은 공통이며, 전공지식을 선택하면 같은 수업 경험·전공 지식·공부 방법을 평가합니다. 이용 이유를 변경하면 이전 분야의 수업과 점수는 초기화됩니다.
