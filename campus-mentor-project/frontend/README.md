# 프론트엔드

## 화면

| 경로 | 설명 |
|------|------|
| `main.html` | 팀 플로우: 학적·이용 이유·수업·선배 유형(1~5점) 선택 후 `/api/match` |
| `concern/` | 고민 문장 입력 → LLM/stub 분석 → 매칭 (백엔드 매칭 플로우) |
| `result/` | 매칭 결과 표시 |
| `chat/` | 대화 프로토타입 |

선택 완료 시 `sessionStorage`의 `ppunppun-choice`에 JSON을 저장하고 백엔드에 추천을 요청합니다. 하단 메뉴에서 선택창으로 이동할 수 있습니다. 채팅을 시작하려면 선택창에서 예시 선배를 선택합니다.

## 실행

## 백엔드 연동

선택 완료 시 로컬 백엔드 `http://127.0.0.1:8000/api/match`에 POST 요청을 보냅니다. 선택값은 `extraction` 형식으로 변환합니다. `interests`에는 수업, `help_fields`에는 이용 이유, `situation`에는 학적과 모든 선택값 및 점수를 담습니다. 응답은 `sessionStorage`의 `ppunppun-match`에 저장한 뒤 선택창으로 이동합니다. 실패하면 입력을 유지하고 재시도할 수 있습니다. 백엔드 실행 방법은 `backend/README.md`를 확인하세요.

현재 백엔드 매칭은 관심사와 도움 분야 및 상황의 텍스트를 비교하며, 1~5점과 수업 이력을 구조화된 조건으로 직접 평가하지 않습니다. 이 항목들이 정확하게 매칭에 반영되려면 백엔드의 요청 스키마와 매칭 로직 확장이 필요합니다. `extraction`을 직접 보내므로 현재 요청에서 LLM 추출은 실행되지 않습니다.

## 선배 선택 화면

`choice/index.html`은 현재 `chat/mock-data.js`의 예시 선배를 표시하고 각 예시 채팅으로 연결합니다. 백엔드 추천 결과는 아직 선택창에 반영하지 않습니다. 백엔드의 선배 ID와 채팅의 예시 번호가 다르므로 팀에서 ID 형식을 합의한 뒤 실제 추천 결과와 연결해야 합니다. 채팅은 현재 같은 브라우저에서 테스트하는 예시 기능입니다.
