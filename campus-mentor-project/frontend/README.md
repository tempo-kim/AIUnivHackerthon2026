# 프론트엔드

## 화면

- `main.html`: 후배의 학적과 이용 이유 선택, 고민 작성, 추천 요청. 선배 진입 버튼에서 기본 정보와 서술형 소개를 입력하고 확인할 수 있습니다.
- `result/`: 백엔드 추천 결과와 이유를 표시하고, 선택한 선배의 채팅 화면으로 연결합니다.
- `chat/`: 예시 대화 화면.
- `concern/`: 별도로 만든 고민 입력 화면.

## 메인 화면 연동

메인 화면은 학적과 이용 이유를 선택하고, 자동 문장 뒤에 자유롭게 내용을 입력합니다. 자동 문장과 추가 내용을 합쳐 `POST /api/match`에 `concern_text`로 전송하며 `use_llm: true`를 전달합니다. 입력된 학적과 이용 이유는 `ppunppun-choice`, 전체 문장은 `ppunppun-concern`, 응답은 `ppunppun-match`로 `sessionStorage`에 저장합니다. 성공 시 실제 추천 결과를 보여주는 `result/index.html`로 이동합니다.

백엔드에 LLM 키가 설정되지 않았거나 백엔드의 처리 방식에 따라 임시 추출 결과가 사용될 수 있습니다. 서버 실행은 `backend/README.md`를 참고하세요. 채팅 메시지 저장과 대화방 연결 상태는 채팅·백엔드 담당자와 확인이 필요합니다.

## 선배 소개 프로토타입

선배는 닉네임, 전공, 학년 또는 졸업 여부와 자유 서술형 소개를 입력합니다. 확인 화면의 임시 저장은 브라우저 탭의 `sessionStorage` 키 `ppunppun-senior-draft`에만 저장하며, 서버 등록이나 실제 매칭에는 반영되지 않습니다. 테스트용 JSON 파일 내려받기는 브라우저의 다운로드 설정에 따라 저장됩니다. `mentor-profile.json`에는 `schema_version`, `display_name`, `major`, `status`, `introduction`이 들어갑니다. 이는 프론트엔드 테스트 형식으로, 백엔드 등록 API 형식이 아니므로 백엔드 담당자와 필드 및 등록 방식을 합의해야 합니다. 가상 정보로 테스트하세요.

## 학교 선택

`universities.js`는 한국대학교육협의회 전국대학및전문대학정보표준데이터(공공데이터포털, 데이터 기준일 2026-03-18)의 학교명 목록입니다. 중복 학교명은 제거하고 같은 학교에 속한 세부 대학원은 `학교명 대학원`으로 묶었습니다. 본교·분교 등 원본에서 이름이 다른 학교는 구분합니다. 소속 학교를 확실히 식별할 수 없는 대학원은 원본 이름을 유지합니다. 대학원 등을 포함한 원본 기준 목록이며 폐교 여부 및 최신 변경 사항은 별도 확인하지 않았습니다. 출처: https://www.data.go.kr/data/15107736/standard.do

선택한 학교는 브라우저의 `localStorage` 키 `ppunppun-school`에 남아 같은 브라우저의 재방문 때 복원됩니다. 후배의 고민 본문에 학교명이 포함되어 `/api/match`로 전달됩니다. 현재 백엔드는 별도 학교 필드를 받아 저장하거나 학교별로 선배를 필터링하지 않습니다. 선배 소개 JSON과 탭의 임시 저장에도 학교가 포함되지만, 현재 선배 등록 API가 없어 서버에 전송하거나 저장하지 않습니다. 선배 등록 엔드포인트와 학교별 저장·매칭은 백엔드 담당자와 합의해야 합니다.

선배 소개 임시 저장 후 선배용 홈에서 본인 소개와 대화 요청 준비 상태를 볼 수 있습니다. 대화 요청 목록은 아직 연동되지 않았으며, 선배 정보는 서버에 등록되지 않습니다. 같은 탭에서 같은 학교로 다시 선배로 시작하면 임시 저장한 소개를 보여줍니다.


## 학점온도와 배지

`assets/achievements.js`를 메인과 추천 결과 화면에서 사용합니다. 선배 화면 오른쪽 위 학점온도는 0.000으로 시작하고 최대 4.500입니다. 클릭하면 0.500 간격의 칭호를 볼 수 있습니다. 점수 산정/적립 기준과 서버 연동은 아직 없으며 실제 학점이 아닙니다.

배지는 로그인한 사용자 ID별로 브라우저에 저장합니다. 첫걸음과 인연 탐험가는 후배의 서버 채팅 이력으로도 다시 계산하므로 로그인 환경이 바뀌어도 달성 상태를 복원할 수 있습니다. 그 외 프로토타입 배지와 선배 ID 목록은 브라우저 저장소에 남으며, 브라우저 데이터 삭제 시 초기화됩니다.

- 선배: 반가운 선배(소개 임시 저장), 경험 나누미(200자 이상 소개 임시 저장), 준비된 선배(테스트 JSON 다운로드 동작).
- 후배: 용기 있는 한마디(직접 쓴 고민으로 추천 요청 성공), 새로운 인연(비어 있지 않은 추천 결과), 첫걸음(선배에게 첫 메시지 전송 성공), 인연 탐험가(서로 다른 선배 3명에게 메시지 전송 성공).
- 같은 배지는 반복 지급하지 않습니다. 선배 활동 점수는 아직 서버에 연동되지 않았습니다.


## 관심 선배와 다시 추천받기

추천 결과 카드에서 찜을 추가·해제하고 관심 선배 탭에서 목록을 확인합니다. 저장 키는 `ppunppun-favorites-v1:<junior_id>`이며 로그인하지 않았다면 `guest`입니다. 같은 브라우저에 선배 정보 사본을 저장하며 DB 저장·기기 간 동기화는 하지 않습니다. 브라우저 데이터 삭제 시 사라집니다.

‘다른 선배 보기’는 지금까지 추천한 선배를 제외하고 다음 후보를 요청합니다. 서버에 등록된 선배 프로필도 후보에 포함됩니다. 하단 채팅 메뉴는 로그인한 후배의 서버 대화 기록을 표시하며, 데이터 기반 선배와의 대화 종료는 자동 동의 처리됩니다.
